# FRAME Festival - Experiencia web para festival de cine

Experiencia web multipágina para un festival de cine de suspense, con diseño visual, navegación, contenido de películas y recorrido de compra simulado.

## Demo

- Web: [https://frame.uiverse.es/](https://frame.uiverse.es/)

## Objetivo del proyecto

FRAME Festival está planteado como una experiencia digital para presentar un evento cinematográfico con una identidad visual marcada. El proyecto combina narrativa visual, estructura de contenidos e interacción Front-End para simular el recorrido completo de un usuario: descubrir el festival, consultar películas y acceder a la compra de entradas.

## Páginas principales

- Inicio del festival.
- Listado de películas.
- Página de información de película.
- Contacto.
- Compra de entradas.
- Datos de pago.
- Confirmación y error de pago.

## Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- Git y GitHub
- Vercel

## Decisiones UX/UI

- Identidad oscura y cinematográfica para reforzar el tono de suspense.
- Navegación clara entre programación, contacto y compra.
- Jerarquía visual pensada para destacar cartelera, fechas y llamadas a la acción.
- Flujo de compra simulado para mostrar un recorrido de producto más completo.
- Búsqueda y elementos interactivos con JavaScript.
- Diseño responsive para adaptar la experiencia a móvil y escritorio.

## Qué demuestra este proyecto

- Diseño de una experiencia web multipágina.
- Dirección visual aplicada a un evento.
- Organización de información y navegación.
- Maquetación responsive.
- Interacciones con JavaScript.
- Construcción de un flujo de usuario desde descubrimiento hasta compra simulada.
